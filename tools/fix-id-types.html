统一ID类型

问题分析

当前数据中ID类型混乱：

  • 地标ID：数字（如 1775197583614）
  • 任务ID：数字（如 1775199267334）
  • 关卡ID：数字（如 1775200856627）
  • 检查项ID：数字（如 1775200808485）
  • 但作为对象键时是字符串

这导致遍历查找时类型不匹配，返回 undefined，进而生成重复ID。

修复方案

将所有ID统一转为字符串类型，包括：

  1. landmarks[].id
  2. landmarkQuests 的键和任务ID
  3. questLevels 的键和关卡ID
  4. 检查项ID
  5. 日历记录中的 checkpointId
  6. checkpointCompletions 的键
